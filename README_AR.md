# SASMAN RADIUS Cloud — نسخة أولية

## الموجود في هذه النسخة
- تسجيل دخول مدير.
- لوحة رئيسية عربية.
- قاعدة SQLite دائمة عبر Docker volume.
- إدارة المشتركين والباقات.
- تسجيل الدفعات وعرض الدين التقديري.
- تواريخ البداية والانتهاء والتجديد المحلي.
- سجل أساسي للعمليات.
- صفحة فحص `/health`.

## تنبيه مهم
هذه نسخة تأسيسية لإدارة البيانات فقط. **لم يتم تنفيذ تكامل MikroTik API بعد**؛ لذلك لا تنشئ/تحذف/توقف حسابات على الراوتر، ولا تعرض حالة الاتصال الحقيقية. أي إضافة أو تعديل أو تجديد في هذه النسخة يؤثر على قاعدة SASMAN فقط. لا تستخدمها بعد لإدارة المشتركين الفعليين قبل إضافة التكامل واختباره.

## تشغيل تجريبي محلي
يتطلب Docker و Docker Compose:
1. انسخ `.env.example` إلى `.env`.
2. غيّر `ADMIN_PASSWORD` و `SECRET_KEY` إلى قيم طويلة وعشوائية وفريدة.
3. شغّل: `docker compose up -d --build`
4. افتح `http://SERVER-IP:8080/login` على شبكة اختبار موثوقة.

## نشر آمن
- لا تفتح منفذ 8080 مباشرة للإنترنت كحل إنتاجي.
- استخدم نطاقاً و HTTPS عبر reverse proxy مثل Caddy أو Nginx.
- فعّل جداراً نارياً وتحديثات النظام والنسخ الاحتياطي.
- لا تضع بيانات دخول MikroTik داخل المستودع أو ملفات عامة.
- لا تفتح MikroTik API للإنترنت العام؛ الأفضل VPN site-to-site أو WireGuard من VPS إلى الشبكة، أو نفق آمن مدروس.
- جهّز نسخة احتياطية واختبر الاستعادة قبل التشغيل الفعلي.

## ما يلزم لإكمال الربط مع MikroTik
1. تأكيد RouterOS 7.20.1 وطريقة المصادقة الحالية.
2. إنشاء مستخدم API مخصص بصلاحيات أقل ما يمكن، وعدم استخدام حساب admin.
3. تحديد عنوان وصول آمن من VPS إلى الراوتر.
4. قراءة فقط أولاً: فحص PPP secrets و active sessions و profiles.
5. اختبار على مستخدم تجريبي واحد.
6. بعدها تنفيذ إنشاء/تعديل/تعطيل وتجديد وفصل الجلسة، مع سجل عمليات وتراجع.
7. تصميم انتهاء الاشتراك وفق مصدر الحقيقة المعتمد، مع منع الفصل الخاطئ والتعامل مع انقطاع VPS.

## إعدادات الباقات الافتراضية
- 7 Mbps تنزيل/رفع، 30 يوماً، السعر 30.
- 10 Mbps تنزيل/رفع، 30 يوماً، السعر 35.
عدّلها من واجهة الباقات.
